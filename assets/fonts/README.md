# Локальные шрифты

Шрифты получены 2026-10-03 из официального репозитория Google Fonts и упакованы в WOFF2 с помощью FontTools 4.61.1 и Brotli 1.2.0. Использован полный набор символов, включая кириллицу: подмножества не создавались, глифы, метрики, переменные оси и встроенные сведения об авторстве не изменялись. Формат WOFF2 сжимает данные без потери качества.
