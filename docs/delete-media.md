# Медиа по постоянным адресам `/delete/`

Постоянный адрес ролика:
<https://urbaso.ru/delete/astra/video/video3.mp4>.
Название каталога является частью URL и сохраняется при обновлениях сайта.

## Выдача файлов

`scripts/configure-delete-media.py` добавляет к существующей конфигурации
отдельное правило для изображений и видео в `/delete/`. Правило расположено
после запрета скрытых файлов и не открывает списки каталогов или скрипты.
MP4 выдаётся с MIME `video/mp4` и поддержкой Range-запросов.

Для запуска скачивают этот скрипт и `scripts/configure-performance.py`
из одного проверенного коммита во временный каталог вне webroot.
Перед запуском сверяют контрольные суммы. Скрипт проверяет конфигурацию,
создаёт резервную копию и печатает команду отката. Конкретные серверные
пути и сведения об установке сохраняются в журнале запуска на сервере.

Старый `configure-performance.py` после добавления media-правила останавливается
на неизвестной конфигурации. Не переписывать её прежним шаблоном: это снова
закроет `/delete/`.

## Хранение в Git

В Git сохранены шесть исходных изображений: `delete/astra/1.jpg`, `2.jpg`,
`3.jpg`, `5.png`, `6.png`, `7.jpg`. Суммарный размер — 375 927 байт.
Контрольные суммы совпадают с серверными оригиналами; перекодирование
не выполнялось.

Видео исключены из Git корневым `.gitignore`. Оригиналы видео требуют отдельной
резервной копии. Откат Git-коммита не восстанавливает ролики. Не использовать
`git clean` для очистки каталога с загруженными файлами.

Для принятия уже загруженных изображений предназначен
`scripts/adopt-delete-media.py`. Его и `scripts/install-performance-release.py`
скачивают из одного проверенного коммита вне webroot. После получения целевого
коммита из GitHub скрипт запускают с полным целевым SHA.

Изображения принимаются только при точном совпадении с Git. Установка сохраняет
специальный флаг `S` и указатели веток, создаёт резервную копию и печатает команду
отката. При откате изображения снова становятся неотслеживаемыми файлами,
сохраняя исходное содержимое. Видео и конфигурация Nginx не изменяются.

## Проверка 16 октября 2026 года

Публичный URL ролика возвращает HTTP 206 и MIME `video/mp4` на запрос первого
килобайта. В браузере Chrome подтверждено воспроизведение без ошибки
декодирования: длительность 17 секунд, размер кадра 1920 × 540.
