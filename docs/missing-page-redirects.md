# Перенаправление отсутствующих страниц

В `scripts/configure-delete-media.py` добавлен отдельный режим
`--redirect-missing-pages`. Он применяется поверх проверенной настройки публичных
медиа и не изменяет файлы сайта, HEAD, индекс или ветки Git.

## Поведение

| Запрос | Результат |
| --- | --- |
| Неизвестная страница, например `/old-page`, `/old-page/`, `/old.html` или `/old.php` | HTTP 302 на `https://urbaso.ru/` |
| Неизвестная страница с query-параметрами | Параметры, включая UTM, сохраняются в адресе главной |
| `/` и `/index.html` | Прежнее содержимое главной, без перенаправления |
| Доступные изображения, видео и ресурсы сайта | Прежняя выдача; для видео сохраняется Range 206 |
| Отсутствующие ресурсы, скрытые и служебные пути | HTTP 404 |

Правило действует на `urbaso.ru` и `site.urbaso.ru`. Редиректы получают заголовок
`Cache-Control: no-store`. Существующий инструмент проверки макета на адресе
предпросмотра остаётся доступен.

## Применение и откат

Скачать `scripts/configure-delete-media.py` и
`scripts/configure-performance.py` из одного проверенного коммита в отдельный
каталог вне публичной папки сайта. Сверить контрольные суммы и запустить первый
скрипт с параметром `--redirect-missing-pages`.

Скрипт принимает только известную конфигурацию Nginx, сохраняет резервную копию,
проверяет синтаксис перед перезагрузкой и проверяет HTTP-ответы после неё.
При ошибке применяется автоматический откат. Для ручного отката скрипт печатает
готовую команду; необходимые файлы находятся в резервной копии.

Повторный запуск проверяет уже применённые правила без повторной записи.
Запуск без нового параметра сохраняет прежнее назначение скрипта — настройку
доступа к медиа; это не способ отключить редиректы. Для отмены используется
команда отката из вывода установки.
