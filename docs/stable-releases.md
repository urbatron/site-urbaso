# Стабильные версии

## v1.0.0-first-stable — 2026-10-03

Первая стабильная версия сайта, все девять секций приняты пользователем. Сайт и email хранятся только в карточке «Сохранить в контактах». Видимые контакты — телефон и MAX.

Версия фиксируется Git-тегом `v1.0.0-first-stable` на итоговом коммите слияния в `main`. Не перемещать и не перезаписывать этот тег. Все используемые изображения сохранены в Git.

Проверить идентификатор версии:

```bash
git rev-parse 'v1.0.0-first-stable^{commit}'
```

Для будущего отката сначала сохранить текущие изменения и файлы вне Git, затем опубликовать точный коммит этой версии с сохранением предыдущего состояния. Не откатывать `main` принудительно и не запускать `git reset --hard` или `git clean`. Порядок публикации и восстановления описан в [deployment.md](deployment.md).
