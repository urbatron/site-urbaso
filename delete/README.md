# Публичные медиаматериалы

Каталог `delete` — часть согласованного URL. Его название не означает, что файлы
можно удалять при публикации сайта.

Постоянный адрес ролика:
<https://urbaso.ru/delete/astra/video/video3.mp4>.

## Хранение

- Небольшие изображения добавляются в Git в исходных байтах, без перекодирования.
- Видео остаются в этом каталоге на VPS и исключены из Git через корневой
  `.gitignore`. Это правило не создаёт резервную копию видео: оригиналы необходимо
  хранить отдельно от сервера. Откат коммитов не восстанавливает ролики.
- Не добавлять пароли, настройки, дампы, архивы и другие непубличные материалы.
- Не выполнять `git clean -fdx`: он удаляет в том числе игнорируемые видео.

Nginx выдаёт из `/delete/` только разрешённые изображения и видео. Сам этот README,
скрипты, скрытые файлы и списки каталогов не публикуются.

Порядок включения и проверки: [docs/delete-media.md](../docs/delete-media.md).
